# password-strength-analyser-with-real-time-breach-check
A cybersecurity tool that analyses password strength using entropy rules and checks real-time data breaches to enhance user security.
 Password Strength Analyzer with Real-Time Breach Detection

A smart cybersecurity tool that analyzes password strength and performs real-time breach checks to help users create secure and uncompromised passwords.

 Features
 Password strength evaluation (weak, medium, strong)
 Real-time breach detection using API integration
 Instant feedback for better password creation
 Enhances user security and prevents compromised credentials
 Simple and user-friendly interface
 Technologies Used
Python
Flask (for web interface)
API Integration (for breach detection)
HTML, CSS (frontend)
 How It Works
User enters a password
System analyzes:
Length
Complexity (uppercase, lowercase, symbols, numbers)
Checks if the password exists in known data breaches
Displays strength level and security suggestions
 How to Run the Project
Clone the repository
Navigate to the project folder

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Open in browser:

http://127.0.0.1:5000/
